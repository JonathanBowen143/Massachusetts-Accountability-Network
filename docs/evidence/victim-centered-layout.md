# Victim-Centered Layout

Last updated: June 14, 2026.

This board is not a government organizational chart. It is a victim-centered accountability map.

The primary reading question is: which victims reveal repeated public actors, offices, institutions, procedures, and decision points across Massachusetts accountability lanes?

## Layout Rule

Victim anchors should remain the organizing lanes. Government nodes should act as connective infrastructure: police departments, DA offices, courts, OCME, POST, the Attorney General, and state agencies help explain how the lanes intersect, but they are not the primary scope of the public graph.

This means the visual layout should avoid two extremes:

1. A pure institutional chart, where victims become subordinate examples under agencies.
2. A loose victim catalog, where institutions are only background labels and repeated public actors become hard to see.

The current public board should stay exploratory: users can start from a victim, institution, official, attorney, witness, or connector type and move through the graph. The visible hierarchy should still imply that victims are the reason the map exists.

## Government Backbone

Government nodes are useful when they connect victim lanes. They should be placed and retained when they:

1. Link multiple victim anchors or wrongful-conviction lanes.
2. Explain jurisdiction, prosecution, employment, oversight, court forum, medical-examiner handling, or discipline.
3. Clarify why a public actor appears in more than one accountability lane.

Government nodes should not be promoted merely to complete an agency hierarchy. A missing bureau, division, unit, local department, or court actor belongs on the board only if it explains a victim-centered connector.

## Future View Option

If the project later needs a government-first display, build it as a separate `Institutional View` rather than replacing the current board. That view can group agencies, offices, courts, and oversight bodies more like an organizational chart while preserving the current board as the victim-centered exploratory view.
